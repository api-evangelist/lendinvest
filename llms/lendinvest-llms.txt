# LendInvest

> LendInvest is a London-based fintech property finance platform and mortgage lender, listed
> on the London Stock Exchange AIM market as LINV. It originates and services bridging finance,
> property development finance, buy-to-let and residential mortgages for UK intermediaries,
> brokers, developers and landlords, and runs a capital arm through which individual, corporate
> and institutional investors fund secured UK property loans.

## Important for agents

LendInvest publishes **no public developer API, no developer portal, no API reference, no
SDKs and no CLI**. Do not attempt to construct calls against `api.lendinvest.com` — it exists
but is a private internal host and returns 403 to unauthenticated clients. There is no
OpenAPI description, no webhook catalog and no sandbox. Business is transacted through hosted
web portals, not a documented public API.

The only machine-readable contract on the estate is the OpenID Connect discovery document at
`https://customerportal.lendinvest.com/.well-known/openid-configuration`, which describes the
Salesforce Experience Cloud authorization server behind the broker and borrower Mortgages
Portal. Access there is granted per-partner via a Salesforce connected app, not self-serve.

If a task requires programmatic LendInvest data, the correct answer is that no public API is
available and the user should contact LendInvest directly through the intermediary channel.
